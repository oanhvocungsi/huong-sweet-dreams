## ✨ Interactive Journey & Scenes

1. **Scene A — The Secret Invitation (Thư Mời Bí Mật)**:
   - Atmospheric opening curtain with gold ribbon and wax seal addressed to Hương.
   - Interactive CTA *"Mở món quà nhỏ 🎀"* with smooth unfold transition and user-gesture sound activation.

2. **Scene B — Enter the Sugar Dream World (Thế Giới Giấc Mơ Kẹo Ngọt)**:
   - Editorial centerpiece featuring the dream pastel cake with fluffy clouds and rainbow macarons.
   - Interactive floating treats (*Cupcake, Donut, Trà sữa, Kẹo bông*) that burst into confetti and sound chimes on touch.

3. **Scene C — The Personalized Greeting & Editorial Portrait (Thư Gửi Hương)**:
   - Authentic portrait of Hương in a luxury polaroid frame with golden clips and warm ambient glow.
   - Sincere, witty, and heartwarming Vietnamese letter written specifically for her without generic clichés.

4. **Scene D — The Dessert Surprise (Hộp Quà Patisserie Kỳ Diệu)**:
   - 3D-styled confectionery gift box tied with golden silk ribbons.
   - Dynamic ribbon untying animation and explosive pastel confetti burst (`canvas-confetti`).
   - 4 collectible dessert charms (*Strawberry Cloud Cake, Rose Macaron, Peach Milk Tea, Golden Honey Parfait*) with custom wishes.
   - Secret VIP privileges card for Hương during October 20.
   - Full replayability.

5. **Scene E — A Little Sweetness Generator (Máy Phát Vị Ngọt Của Hương)**:
   - Wholesome randomized sweetness dispenser with 12 unique, refreshing compliments and micro-wishes.
   - Animated spinning candy capsule stage with bubble pop audio FX.
   - "Sao chép lời chúc" (Copy to clipboard) with toast notification.
   - Collectible progress tracker (*Đã nếm thử X/12 vị ngọt*).

6. **Scene F — Chill Remix Turntable Lounge (Góc Nhạc Chill)**:
   - Dedicated vinyl turntable lounge honoring Hương's love for chill remix music.
   - Realistic spinning vinyl record with Hương's photo at the spindle.
   - Real-time audio frequency visualizer powered by Web Audio API `AnalyserNode`.
   - 3 selectable chill tracks:
     - *Chill Sunset Remix* (Lofi Rhodes chords & warm beats)
     - *Sweet Music Box* (Crystal celesta & bell harmonies)
     - *Pastel Dream Waltz* (Ambient airy synth pads)
   - Volume slider & instant mute toggle.

7. **Scene G — The Final Wish & Memory Keepsake (Lời Chúc & Kỷ Niệm)**:
   - Celebratory Women's Day blessing.
   - Interactive wish candle lighting with floating star particles.
   - One-click gift sharing & smooth replay option.

## 🎧 Audio Engineering
- **100% Procedural Web Audio API Engine**: Zero external MP3 network dependencies, zero CORS errors, zero broken links, and instant loading.
- Real-time FFT spectrum analysis feeding live HTML5 canvas equalizers.
- Interactive tactile sound FX: Sparkle chime, Box opening flourish, Bubble pop, and Soft wooden click.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite 8
- **Motion & Interactions**: Framer Motion 14, Canvas Confetti
- **Icons**: Lucide React
- **Styling**: Modern CSS variables, glassmorphism, responsive clamp typography
- **Deployment**: GitHub Pages (`gh-pages` branch & GitHub Actions)

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
